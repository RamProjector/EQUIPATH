# EquiPath

EquiPath is a proposed web-based ETEEAP application, portfolio evaluation, and accreditation tracking system for Asian Development Foundation College (ADFC).

## Approved proposal stack

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Web server: Apache (XAMPP for local development)
- Version control: Git and GitHub

The application must preserve the proposal's workflow: applicant submissions, document screening, portfolio evaluation, assessment scheduling/results, credit recommendations, authorized accreditation decisions, applicant notifications, college-record exchange, reporting, role-based access, audit trails, and recovery procedures.

## Development status

Initial repository bootstrap. Features will be implemented incrementally and validated before being treated as complete. Academic eligibility, credit recognition, and final accreditation remain decisions for authorized ADFC personnel.
